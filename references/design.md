# 高清编辑排版

## 默认方向：A版暖白编辑风

固定采用暖白底、单栏、克制蓝色强调、大新闻标题与舒展段落。不采用窄侧栏，不混入黑白双栏版。去掉纸纹、标题圆角框和重复分隔线；刊名与日期退居辅助层级。重点用内容层级和留白形成质感，不每期重新设计视觉语言。

先按手机实际阅读尺度设计：432 CSS px宽竖版画布，以deviceScaleFactor=5原生渲染，输出2160px宽PNG，不放大已有位图。正文18–19px，行高1.6–1.7，边距24–28px，新闻标题26–30px，来源与辅助文字13–14px。每行约20–22个汉字；同时在390px显示宽度验收，不能只看高清原图。

每页一个重点或两条短新闻，增加页数而不是缩小字号；图片是精编阅读版，不把完整桌面文档挤成几张截图。标题与摘要必须同页；避免无主题续文、标题断词、段尾一两个孤字和过量上下空白。保留事实、限制、判断的独立层级。中文字体先检查可用性并等待document.fonts.ready。

采用暖白/象牙纸底、炭黑文字、单一低饱和深蓝/酒红/墨绿强调色；细线、留白、基线网格、明确日期和页码。像有编辑设计的杂志，不是卡片堆叠。不要荧光渐变、过多emoji、密集多栏、装饰性AI图片。不要为封面浪费整张图。

HTML完整展示来源链接，图片用简短来源标签。核心博客标题带公司前缀。图文同源，精简也不能删除日期、条件、风险和金额。图片不必一板块一页，长篇可以跨页且阅读顺序明确。

验收：用DOM尺寸检查越界，逐页视觉查看是否缺字、遮挡或裁切；核对PNG实际尺寸、页数、顺序；同时查看手机尺度。保留高清原文件，聊天平台可能压缩。

图片正文必须自洽，禁止出现“详见HTML”“详见网页”“完整版见网页”等把阅读责任推回网页的元话术。可在聊天正文附HTML链接，但图片内不能用这类提示代替完整句子、关键事实、限制条件或来源标签。

渲染器应使用内容自适应高度。不要用固定height、min-height、flex space-between或底部锚定页脚制造大片空白；最后一段正文或来源后保留约24–36 CSS px即可结束画布。短讯可合页，不能为了固定页数生成空标题页或半页空白。

禁止用省略号、截断数组或裁切画布来缩短图片正文。长条目需要分页时，在完整语义边界断开，并在续页保留清晰主题提示；不得截断句子、删除关键限定或把来源移到不可见区域。
